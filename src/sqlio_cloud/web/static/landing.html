The comprehensive cloud database benchmark suite. Measure I/O throughput, query optimizer efficiency, transaction integrity, and network characteristics — all through standard SQL, no agents required.

Inspired by SQLCAT. Microsoft's SQL Server Customer Advisory Team ran an internal performance lab where customers brought their own workloads to stress-test against real hardware — measuring IOPS with SQLIO, validating storage integrity with SQLIOSim, and benchmarking query optimizers with decision-support workloads. That lab was only accessible to a select few. CloudBench gives you the foundational tools from that lab — I/O profiling, integrity verification, analytical benchmarks, and network diagnostics — rebuilt from scratch for the cloud era, where there is no disk to test and no lab to visit. It won't replay your production workload, but it will tell you exactly what your cloud database tier is capable of before you deploy one.

I/O Performance Testing

Random reads, random writes, sequential scans, mixed workloads, and bulk inserts — with configurable block sizes from 1 KB to 64 KB. Thread scaling sweeps reveal saturation points and Amdahl's serial fraction.

✓

Data Integrity Verification

SHA-256 checksums on every page written. Concurrent stress with balance-conservation audits. Isolation level anomaly detection. If your database silently corrupts data, CloudBench will find it.

⚙

Analytical Query Benchmark

16 original decision-support queries on a star-schema dataset. Cold and warm execution to measure plan cache effectiveness. Geometric mean and power score for cross-comparison.

☁

Network Profiling

DNS resolution, ping latency distribution, connection setup overhead, first-byte latency, and bidirectional bandwidth measurement. Know exactly where your performance floor is.

⇵

Thread Scaling Analysis

Every I/O test runs at multiple concurrency levels. The scaling curve identifies optimal thread counts, saturation points, and the serial fraction — directly informing connection pool sizing.

☑

Export-Ready Reports

Branded PDF reports for stakeholders. Flat CSV for spreadsheet comparison across servers. Structured JSON for programmatic analysis. Every filename includes host, preset, and timestamp.

How It Works

1

Provision a Test Server

Spin up a dedicated database on the cloud tier you want to evaluate. Any SKU, any provider. CloudBench needs a blank database and a SQL login — nothing else.

2

Connect

Enter your host, port, credentials, and database engine. CloudBench validates the connection, detects the server version, and confirms connectivity before any tests run.

3

Choose Your Benchmark

Pick a preset — Smoke (5–15 min), Standard (20–60 min), or Full Stress (60+ min) — or customize individual tests and block sizes. The preset is a starting point; toggle any test on or off.

4

Run

CloudBench executes each test with live progress streaming. Watch operation counts tick up in real time. No agents are installed on your database — everything runs through standard SQL over the network.

5

Analyze and Export

Interactive results with latency histograms, thread-scaling charts, and per-metric tooltips written for database engineers. Download a PDF report, CSV for spreadsheet comparison, or JSON for programmatic analysis.
